## 1. Багатотабличний запит з групуванням (Параметричний)

**Умова запиту:** 
Отримати загальну кількість проданих одиниць та загальну суму продажів для кожної категорії товарів за вибраний період часу. (Запит дозволяє оцінити, які категорії приносять найбільший прибуток).

**SQL-код запиту:**
```sql
SELECT 
    c.category_name AS "Категорія", 
    SUM(s.product_number) AS "Продано одиниць", 
    SUM(s.product_number * s.selling_price) AS "Загальна сума"
FROM categories c
JOIN products p ON c.category_number = p.category_number
JOIN store_products sp ON p.id_product = sp.id_product
JOIN sales s ON sp.upc = s.upc
JOIN checks ch ON s.check_number = ch.check_number
WHERE ch.print_date BETWEEN :startDate AND :endDate
GROUP BY c.category_number, c.category_name
ORDER BY "Загальна сума" DESC;
```

## 2. Багатотабличний запит з подвійним запереченням

**Умова запиту:** 
Знайти товари (унікальні ідентифікатори та назви), які були продані **всіма** касирами. 
*(Логіка подвійного заперечення: Знайти такі товари, для яких НЕ існує такого касира, який би НЕ продав цей товар).*

**SQL-код запиту:**
```sql
SELECT p.id_product, p.product_name
FROM products p
WHERE NOT EXISTS (
    -- Вибираємо всіх працівників з роллю CASHIER (Касир)
    SELECT e.id_employee
    FROM employees e
    WHERE e.empl_role = 'cashier'
    AND NOT EXISTS (
        -- Перевіряємо, чи є факт продажу цього товару цим касиром
        SELECT 1
        FROM sales s
        JOIN checks ch ON s.check_number = ch.check_number
        JOIN store_products sp ON s.upc = sp.upc
        WHERE ch.id_employee = e.id_employee
          AND sp.id_product = p.id_product
    )
);
```

### Крок 1. Frontend (React) - Відправка запиту
Користувач обирає дати та натискає кнопку. Виконується HTTP GET запит до сервера за допомогою `axios`.

```typescript
// reportApi.ts - Формування тексту запиту та пересилка серверу
import axios from 'axios';

export const reportApi = {
  getCategorySales: async (startDate: string, endDate: string) => {
    // Встановлення з'єднання та пересилка серверу (через axios інстанс)
    return await axios.get('/api/v1/reports/category-sales', {
      params: { startDate, endDate }, // Передача параметрів
      headers: {
        Authorization: `Bearer ${localStorage.getItem('token')}`
      }
    });
  }
};

// Component.tsx - Обробка події натискання кнопки
const handleGenerateReport = async () => {
    try {
        // Відправляємо запит
        const response = await reportApi.getCategorySales('2023-01-01', '2023-12-31');
        // Отримання та обробка відповіді для відображення в UI
        setReportData(response.data); 
    } catch (error) {
        console.error("Помилка завантаження звіту", error);
    }
};
```

### Крок 2. Backend (Spring Boot Controller) - Отримання запиту
Контролер приймає HTTP запит, валідує параметри та передає їх у сервіс.

```java
// ReportController.java
@RestController
@RequestMapping("/reports")
public class ReportController {

    @Autowired
    private ReportService reportService;

    // Прийом GET-запиту з параметрами startDate та endDate
    @GetMapping("/category-sales")
    public ResponseEntity<List<CategorySaleDto>> getCategorySales(
            @RequestParam @DateTimeFormat(iso = DateTimeFormat.ISO.DATE) LocalDate startDate,
            @RequestParam @DateTimeFormat(iso = DateTimeFormat.ISO.DATE) LocalDate endDate) {
        
        // Виклик сервісу для виконання бізнес-логіки
        List<CategorySaleDto> result = reportService.getCategorySales(
                startDate.atStartOfDay(), 
                endDate.atTime(LocalTime.MAX)
        );
        return ResponseEntity.ok(result); // Повернення відповіді у форматі JSON
    }
}
```

### Крок 3. Backend (Spring Boot Repository) - Виконання SQL-запиту
Використання `NamedParameterJdbcTemplate` для формування параметризованого SQL-запиту, що захищає від SQL-ін'єкцій.

```java
// ReportRepositoryImpl.java
@Repository
public class ReportRepositoryImpl {

    @Autowired
    private NamedParameterJdbcTemplate namedJdbc;

    public List<CategorySaleDto> getCategorySales(LocalDateTime startDate, LocalDateTime endDate) {
        // Формування тексту SQL-запиту
        String sql = """
            SELECT 
                c.category_name, 
                SUM(s.product_number) AS total_amount, 
                SUM(s.product_number * s.selling_price) AS total_sum
            FROM categories c
            JOIN products p ON c.category_number = p.category_number
            JOIN store_products sp ON p.id_product = sp.id_product
            JOIN sales s ON sp.upc = s.upc
            JOIN checks ch ON s.check_number = ch.check_number
            WHERE ch.print_date BETWEEN :startDate AND :endDate
            GROUP BY c.category_number, c.category_name
            ORDER BY total_sum DESC
        """;

        // Прив'язка параметрів до запиту (встановлення з'єднання виконується під капотом Spring)
        MapSqlParameterSource params = new MapSqlParameterSource()
                .addValue("startDate", startDate)
                .addValue("endDate", endDate);

        // Пересилка запиту до БД, отримання результату та мапінг його у DTO об'єкти
        return namedJdbc.query(sql, params, (rs, rowNum) -> new CategorySaleDto(
                rs.getString("category_name"),
                rs.getInt("total_amount"),
                rs.getBigDecimal("total_sum")
        ));
    }
}
```
